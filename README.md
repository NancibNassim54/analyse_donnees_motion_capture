# 📊 Motion Capture Kinematic Analysis: Young vs. Elderly Subjects

> A data science and cognitive science project comparing finger-reaching movement dynamics and motor control between young and elderly cohorts.

## 🎯 About the Project
This project focuses on the quantitative analysis of motion capture kinematic datasets. By processing and comparing movement metrics (such as velocity profiles, trajectory smoothness, and reaction times), the study highlights age-related differences in fine motor control and movement execution dynamics.

## 🔍 Key Analysis & Methodology
* **Data Processing:** Handling and resampling high-frequency kinematic time-series data (e.g., from 200Hz to 60Hz).
* **Kinematic Metrics:** Extracting peak velocity, movement duration, deceleration phase ratios, and spatial precision.
* **Comparative Statistics:** Statistical evaluation between young and elderly subject groups to identify significant behavioral variances.
* **Data Visualization:** Plotting trajectory curves, velocity profiles, and comparative distributions.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Signal Processing & Statistics:** SciPy, Scikit-learn
* **Visualization:** Matplotlib, Seaborn
